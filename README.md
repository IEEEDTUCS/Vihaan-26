## ✨ Key Features

### 🎟️ Live QR-Based Attendance & Identity System
A seamless onboarding experience for participants during the event check-in process.
- **Dynamic Linking:** Participants are handed a physical ID card with a random QR code upon arrival.
- **Instant Activation:** The QR is scanned and instantly linked with the unique RSVP code sent to the participant's registered email.
- **Unified Identity:** Once linked, the physical ID card acts as the user's digital footprint for the rest of the event, used for identification, meal tracking, and access control.

### 👤 Comprehensive User Dashboard
A centralized hub for participants to manage their hackathon journey (accessible only after ID card linkage).
- **Project Submissions:** Teams can submit their final project details (currently restricted to team leaders).
- **Milestones & Anti-Cheating Checkpoints:** Keeps a record of team progress. Software teams must submit regular commit links, while hardware teams upload progress images, ensuring fair play and steady momentum.
- **Logistics Tracking:** Participants can track their event logistics in real-time, including how many meals they've redeemed, whether they've collected their bedsheet, and their allotted room number.

### ⚙️ Powerful Admin Dashboard
The ultimate control center for organizers to run the event smoothly.
- **Data Management:** Full access to view and manage all participant and team data.
- **Event Logistics:** Assign room numbers, track live present/absent status, and monitor inventory distribution (meals, bedding).
- **Judging & Evaluation:** Tools for assigning marks and managing the evaluation pipeline.

## 🚀 Future Scope & Improvements
While this project served as a robust backbone for Vihaan 9.0, we have identified areas for future enhancement:
- **User Dashboard:** Improve the logic for team-based project submissions (better handling of leader vs. member roles).
- **Judging Transparency:** Implement a dedicated section on the user dashboard to showcase judge feedback and final scores/marks.
- **Admin Capabilities:** Expand the admin dashboard with more granular analytics, bulk-action features, and advanced judging allocation tools.
